# Synthetic demonstration packets

Every file in this directory is fictional demonstration content. It contains no real PHI and does not represent a real payer, policy, clinical record, or coverage decision. The files exist for local upload, extraction, and Loom demonstrations only.

- `RM-PA-1047_Marcus-Lee/` is a complete, internally consistent packet.
- `RM-PA-1048_Elena-Torres/` is intentionally incomplete and omits a PT/OT evaluation.
- `RM-PA-1042_Amira-Hassan/` is a denied case with supporting evidence and an accessory-justification gap.
- `RM-NEW-CASE_Demo-Patient/` is specifically for demonstrating new-case creation from a document dump; it includes one intentionally ambiguous equipment detail.
